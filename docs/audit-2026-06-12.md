# Platform Audit — 2026-06-12

Full-stack audit: 3 parallel deep-code analyses (architecture, dependency tracing, bug hunt) + live
browser testing of the admin panel, impersonation, and the Telegram bot, + live-DB cron/RLS checks.

## 1. Architecture verdict (summary)

Solid core: React/Vite frontend with role-gated routes; 30+ edge functions; well-triggered DB
(streak/badge/guard triggers); 15 live cron jobs. The **canonical homework "effective grade"
pipeline is consistent** across web profile/lesson/admin, bot /galaba, SQL views, and the
leaderboard recalc — pinned by a parity test. Main structural risks: a 4,532-line monolithic bot
file, duplicated leaf/effective-grade logic in ~10 call sites (3 of them divergent), cron jobs
that exist only in the live DB (not in migrations), and 2 missing FKs.

## 3. Dependency map (the "one write → many readers" question)

**Homework submission/grade →** /galaba (live+30s cache, invalidated ✔) · /vazifalar (live, but H1) ·
web profile/lesson/admin views (live, canonical ✔) · leaderboard (15-min cron, M8) · first_homework
badge (trigger ✔) · teacher DM (queue+cron, idempotent ✔, M2 when no teacher) · /ttop & /tstats (M5)
· analytics MVs (nightly).

**Group create/move →** topic resolution (bot ✔ / web M4) · teacher DMs (M2) · group leaderboard
(live membership ✔, M3 archived) · star-of-week (Mon cron ✔; departed star cosmetic) · engagement
events (M7) · teacher keyboards (live ✔). Student moves propagate live everywhere except the
old group's frozen weekly star.

## 4. Top-5 UI/UX improvements (proposed)

1. **Fix names at the source** — one-time bot flow: ask each student to confirm/enter their real
   name (+ admin bulk-edit screen). Unblocks leaderboard/star/share-cards social value (H5).
2. **Impersonation round-trip** — restore admin session on Exit (store return token), error toast
   on user-not-found, banner on first load (H3).
3. **One truth for "active"** — single labeled activity definition on the admin dashboard; fix the
   30d bucket; uncap logins; exclude staff from student lists (H4).
4. **Same homework status everywhere** — fix /vazifalar effective-grade (H1) + web shared-topic
   fallback (M4); teachers and students stop seeing contradictions.
5. **Leaderboard page refresh** — group-first view (match bot), show viewer's own row, honest
   "updates every 15 min" copy (L7).

## 5. Feature suggestions

**Teachers:** (a) Daily digest DM — pending-homework count + at-risk students + one-tap grade
links; (b) "Grade-next" rapid grading flow in web (queue + hotkeys); (c) Weekly group health card
(active %, streak distribution, top movers) auto-DM'd Monday.

**Students:** (a) Shareable achievement cards (already designed — 7 templates ready); (b) Weekly
quests ("3 dars + 1 vazifa" with progress bar; reward = streak freeze); (c) Visual module journey
map; (d) /davom deep-link nudge that resumes the exact lesson at the saved position.
