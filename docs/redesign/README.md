# AI Creators redesign — visual source of truth

Open `mockup.html` in a browser: the full 11-screen student Mini App in the approved
**Graphite & Emerald** look (Onest/Unbounded, coral CTA). Use the top page selector or the
phone bottom tabs to move between screens. This is the pixel reference the implementation
plan builds against, alongside the spec (`docs/superpowers/specs/2026-08-17-ui-redesign-design.md`).

Screens: home, home-empty (first-run), darslar, lesson, homework, upload, up-success,
up-error, hw-detail, reyting, profil. Certificate lives separately in `docs/certificate/`.
